# 08：界面启动入口、翻译上下文与显示名称

## 哪一项必须跟着前面改？

**启动 stub 中的 EXE 名称，需要跟随实际界面 EXE 改名。** 这个 stub 是一个启动小程序：找到自身目录，再启动同目录下的 `qrenderdoc.exe`。如果界面已改为 `qrendertest.exe`，这里仍找旧名，就无法从这个入口正常启动。

这与第 04 节是两个不同的查找入口，都要核对；只修改窗口标题不会改变它们寻找的文件名。

其余几项主要用于翻译或显示，不是 EXE 改名后必须同步修改的启动依赖。

## 两个容易误解的地方

**“会话名”实际是 Catch 单元测试的会话名称。** 它不控制 Windows 登录会话、捕获会话或主程序名称，不能用它来完成 EXE 改名。

**翻译上下文是查译文时用的标识，不是界面显示名称。** 修改后，若已有翻译资源仍按旧上下文组织，对应译文可能找不到而退回原文；帮助说明的原文变化也可能需要更新对应翻译。没有使用翻译资源时，改它通常不会产生可见效果。
