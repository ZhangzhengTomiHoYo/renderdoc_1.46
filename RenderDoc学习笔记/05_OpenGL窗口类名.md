# 05：OpenGL 窗口类名

## 这次改的是什么？

这是 Windows 的**窗口类名**：注册一套窗口行为时给它起的名字，创建窗口时再用这个名字指定采用哪一类。它不是 C++ 类名，也不是窗口标题。

**与前面的 EXE、DLL、marker 改名没有必须同步的关系。** 这里需要一致的是“注册窗口类”和“创建窗口”使用的名称。

当前文件两边都使用同一个宏 `WINDOW_CLASS_NAME`，所以修改宏后，重新编译就能让这些使用点一起更新，不需要逐个修改。
